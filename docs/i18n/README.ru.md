XCL2 — независимый игровой лаунчер для Windows, ориентированный на управление экземплярами Minecraft. Он объединяет загрузки, учётные записи, моды и модпаки, сетевые инструменты, показатели производительности и ИИ-помощника. Можно сохранить привычный интерфейс или включить предварительный просмотр нового оформления, настроить темы, анимации, сочетания клавиш и сенсорное управление.

**Это репозиторий исходного кода.** Кнопка GitHub «Download ZIP» скачивает исходники, а не установщик. Готовая программа доступна только тогда, когда сопровождающие действительно публикуют её в разделе Releases. Здесь не предполагается наличие ещё не выпущенной версии или ссылки на неё.

## Возможности

| Раздел | Что доступно |
| --- | --- |
| Экземпляры и аккаунты | Управление игровыми экземплярами, параметрами запуска, средами Java и учётными записями. |
| Контент | Загрузка версий, управление модами, модпаками, ресурс-паками, шейдерами, мирами и очередью загрузок. |
| ИИ-помощник | Диалоги, вложения, история, выбор модели и режимы для исследования, планирования и разрешённых действий с отображением процесса выполнения. |
| Сеть и серверы | Управление серверами, диагностика соединения и интеграция Terracotta при наличии необходимых служб и зависимостей. |
| Интерфейс | Светлая и тёмная темы, языки, параметры анимации, сенсорные кнопки, горячие клавиши, монитор производительности и настройки отображения поверх окон. |
| Экспериментальные функции | Раздел Mini World и загрузки по CDK или прямой ссылке после подтверждения ознакомления; нужны действительные источники, поддерживаемые издателем. |

Кнопки копирования и повторной генерации видны постоянно и имеют прозрачный фон с контуром. Подробности выполнения раскрываются и сворачиваются с анимацией. Новый интерфейс меняет оформление существующих разделов и карточек. Язык документации не определяет язык приложения: некоторые экспериментальные разделы пока доступны только при выборе упрощённого китайского интерфейса.

## Начало работы

1. Если готовая версия опубликована, скачайте полный пакет из проверенного раздела Releases исходного проекта. Проверьте издателя, описание выпуска и опубликованные контрольные суммы.
2. Распакуйте весь каталог и запустите `XCL2.exe`. Сохраните зависимости, включая файлы WebView2: одного EXE недостаточно.
3. Настройте аккаунт, папку игры, экземпляр и Java, затем запустите выбранный экземпляр.
4. Для ИИ укажите поддерживаемого провайдера, модель и собственные учётные данные. Доступность, стоимость и обработка данных зависят от провайдера.

Исходники не предоставляют лицензию на игру, права на платные ресурсы или универсальные CDK. XCL2 не связан официально с Mojang, Microsoft или другими правообладателями игр и не одобрен ими. Открытая лицензия проекта не заменяет условия третьих сторон.

## Сборка из исходников

Нужны Windows с графическим рабочим столом и .NET 8 SDK. Целевая платформа основного проекта — `net8.0-windows10.0.19041.0`, заявленный минимум — Windows 10 1809; у отдельных модулей могут быть дополнительные требования. Предусмотрены конфигурации x86, x64 и ARM64, но не все внешние компоненты поддерживают все архитектуры.

Существующий модуль Bedrock требует **`XCL2_PRE_KEY` и `XCL2_REL_KEY`, по 96 шестнадцатеричных символов каждый**. Их значения не включены. Подготовив законно доступную конфигурацию сборки, выполните из корня репозитория:

```powershell
dotnet restore .\XCL2.App\XCL2.App.csproj
dotnet build .\XCL2.App\XCL2.App.csproj -c Release -p:SkipNativePreview=true
```

Команда пропускает отдельное приложение предварительного просмотра на WinUI, сохраняя новое оформление внутри WPF. Подробности — в [руководстве по сборке](../BUILDING.md) на китайском и английском. Из-за внешней конфигурации полностью автономная воспроизводимая сборка пока не подтверждена.

Проверки для Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\XCL2.App\Tests\Test-AiPresentation.ps1
powershell -ExecutionPolicy Bypass -File .\XCL2.App\Tests\Test-October29Changes.ps1 -IncludeWindowsUi
```

Предыдущие проверки пакета были статическими. Компиляция и проверка интерфейса в Windows в среде подготовки пакета не выполнялись; успешная сборка не заявляется.
