# 存档可视化回归检查

运行（.NET 8 SDK）：

```sh
dotnet run --project Tests/WorldMapRegression/WorldMapRegression.csproj
```

测试使用独立写入的真实大端 NBT 和按扇区对齐的 MCA 夹具，覆盖 gzip/zlib/raw、负坐标/负 Y、1.13 连续及 1.16 对齐 packed data、空/损坏/未生成区块、读取取消、解压上限。新增地下水平切面、固定 Z 垂直切面方向、XYZ 范围内精确方块计数、坏索引不提交部分统计、等距图像缓冲和绘制取消。

Windows 手动验收：

1. 打开“存档修改 → 存档可视化”，选择 Java 1.13+ 的副本。每次读取前都应出现性能成本提示；取消后不读取。
2. 鸟瞰图可缩放、拖动和查看真实坐标/方块。分别从出生点和玩家位置读取，核对地形。
3. 水平切面设置地下 Y，和游戏相同位置方块核对。垂直切面固定中心 Z，顶部为较高 Y，核对 X/Y/方块提示。
4. 三维样式应随实际地表高度变化，并可导出 PNG。它是地表等距高度投影，侧面为高度示意，不是地下体素建模。
5. 方块分布指定 Y 范围，核对已知简单建筑的计数，导出 PNG 和全部类型 CSV。未生成/无法读取的区块和空气不进入数量。
6. 读取中点击取消、切换维度、切换存档/页面，旧任务结果不得覆盖新状态。输入超限半径、反向 Y 范围或大于 512 层的范围，应明确拒绝。
7. 三维样式和体积统计半径上限 64；其他视图半径 8–256；只读，存档文件应无修改。

格式限制：仅支持 Java 1.13+ Anvil 方块调色板。旧数字 ID、Bedrock LevelDB、外置 MCC 和 LZ4 区块明确显示无法读取及原因，不显示虚构地形。可视化基于磁盘已保存数据，建议先退出游戏/服务器。方块颜色为类别示意色，不是材质包渲染。

当前交付环境无法启动 CoreCLR，因此新增测试代码未在该环境执行；需在可运行 .NET 8 的环境完成上面的自动和 Windows 交互检查。
