# 性能浮窗与便签 Windows 验收

运行：

```powershell
dotnet run --project Tests/StickyNoteOptionsRegression
dotnet run --project Tests/StickyNoteWindowRegression
dotnet run --project Tests/PerformanceOverlayInputRegression
```

本次编辑环境没有可运行的 .NET/Windows 桌面，因此这些 C# 回归用例尚未执行。XAML/XML 已做结构解析检查。

人工验收：

1. 仅打开性能监视器（不打开便签），选择真正关闭启动器：应出现提示，明确列出性能监视器仍在采样。选择取消保留主界面；选择保留收起到托盘且读数继续刷新；选择一起关闭后退出且停止采样。
2. 同时打开便签与性能监视器：一次提示列出两者；便签保存失败时应拦截退出。若之后在游戏进程关闭确认中取消，再点退出应重新提示活动工具。
3. 右键性能监视器，分别点击启动器内容区、桌面空白、另一程序以及性能浮窗本体：菜单立即关闭，无需切换窗口。外部按钮仍收到这次点击。
4. 点击菜单项、二级/三级子菜单时正常响应。鼠标穿透模式下使用齿轮入口重复上述测试；关闭悬浮窗后不应残留菜单或输入监听。跨 DPI 显示器重复验证边界。
5. 新便签及没有 options 文件的旧便签默认左上对齐，自动大小关闭。工具页与便签右键菜单均可设置两选项，退出重开后保留。
6. 启用自动大小，输入/删除多行文字应扩大/缩小；大量内容不超出屏幕并可滚动。关闭自动大小后可手动拉伸。核验14种外观、横线纸和终端字体。
7. 人为破坏同名 `.options.json` 文件后重开便签：显示读取失败提示，保留原文件与正文，不静默覆盖。

新增文件生命周期回归：工具页未修改时离开保留桌面便签最新正文；真实编辑仍保存；文件读取失败后禁写，恢复读取后可编辑；删除已打开的便签先关闭桌面窗口，避免延迟保存重建文件。
