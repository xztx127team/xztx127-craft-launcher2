# 纯聊天模式

AI 设置与聊天栏的模式菜单新增“纯聊天模式”。原 Build、Plan、Agent 的持久化值不变，Chat 追加为 3。

- 使用独立的简短聊天提示，不附加工作目录、已有授权、命令或电脑操作说明、人格中的执行说明、任务与计划协议。不会自动创建、恢复或修改已有任务。其它模式保存的权限和目录保留，但在纯聊天中全部不生效。
- 请求上下文只携带当前用户消息，以及已知来自纯聊天的历史消息和图片；不带旧执行模式的消息、旧摘要、工具输出、任务目标、路径或步骤。编辑消息产生的分支保留模式来源。历史记录仍可在界面查看。
- 在真正的分发入口拦截命令、目录申请、文件读写、设置、注册表、电脑操作、Plan、子智能体和提问卡；模型输出控制标记不会获得权限，也不触发纠错重试。联网工具同样关闭。
- 只有本轮用户明确要求读取/分析日志，且“允许把用户主动提交的崩溃/日志内容发给 AI 分析”已开启时，才提供一次 read_log 请求。仍须逐次确认，只读取本次启动器运行的内存日志，不申请目录、不读取任意游戏日志文件。说明“如何读取日志”、历史轮同意、模型自称获得同意均不算本轮授权；运行中关闭日志开关会立即阻止读取。用户也可直接粘贴文字日志讨论。
- 纯聊天支持图片；文件和 ZIP 内容请以文字粘贴，避免向模型提供任何临时目录。切换模式时若仍有文件草稿，发送前会说明并保留草稿。
- 每轮捕获最初模式。以纯聊天开始的回复不能中途升级；运行中切换为纯聊天会永久收紧该轮。崩溃分析浮层的只读限制也不能覆盖纯聊天限制。

## 验证

AiHttpRegression 增加高权限配置、旧目录/历史/摘要/任务隔离、控制协议拦截、当前轮日志授权与撤销、模式切换和消息来源持久化用例；AiPermissionsRegression 使用真实配置模型并增加全选/完全访问下的纯聊天拒绝用例。静态源码与 XAML 检查通过。当前环境未提供 .NET SDK，尚未编译或进行 Windows 运行验证。
