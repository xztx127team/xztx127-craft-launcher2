# 30项体验优化与验收

本次是源码交付。当前环境没有 .NET SDK、Windows 或 WPF 图形运行环境；**尚未编译主程序、执行 C# 回归项目或完成实际界面/游戏验收，不能据此承诺全部功能实机通过。** 本文记录实现入口、默认值、已执行的静态检查和待完成的 Windows 验收。

## 入口与默认值

已有用户偏好继续保留。提醒与建议只进入右下角角标，不自动展开、不抢焦点；原有模组更新通知设置保持用户选择。主要操作留在主页面，低频操作集中在相关菜单和默认折叠分区；没有额外叠加阴影。

| 序号 | 功能 | 默认值 | 入口 | 实现与边界 |
|---|---|---|---|---|
| 1 | 设置搜索与定位 | 默认提供 | 设置页搜索；Ctrl+F、Enter / Shift+Enter 导航 | 搜索折叠区；仅导航时展开并以细边框高亮，无发光重影。 |
| 2 | 单项与分组恢复默认 | 提供入口，主动操作 | 设置项右键；分组菜单 | 135 个明确绑定及特殊/动画控件；组重置确认。权限、账号、文件列表和执行动作不参与。 |
| 3 | 收藏与最近使用 | 收藏入口；三类最近记录默认关闭 | 实例菜单与筛选、服务端列表菜单、全部工具菜单 | 实例按目录+ID收藏，服务端按ID，工具按固定工具ID；最近记录分别可关闭和清空。 |
| 4 | 启动前摘要 | 提供入口，主动查看 | 启动按钮右键 / Shift+F10 → 查看启动摘要 | 本地账户状态、实例、运行目录、隔离、Java候选、内存及模组数量；不运行Java、不联网。 |

| 6 | 模组兼容性预览 | 本地检查入口；手动联网检查允许但不自动执行 | 模组页 → 兼容性预览 | 识别常见元数据、加载器/版本/缺失依赖；复杂范围明确标为需核对，不冒充完整依赖求解器。 |

| 9 | 可预览的诊断导出 | 默认脱敏；主动导出 | 日志 → 更多 / 崩溃页菜单 → 诊断导出 | 勾选内容、预览、保存ZIP；导出与预览一致，不自动上传。 |
| 10 | 键盘与无障碍 | 焦点/快捷说明；减少动画默认跟随系统 | 设置 → 使用习惯与隐私；Tab / Shift+Tab | 单层焦点边框、访问键、相关列表Enter；字体沿用已有设置。 |
| 11 | 设置修改摘要 | 有真实修改才显示 | 设置页 → 查看本次修改 / 最近保存的修改 | 不把滚动、搜索、展开、未应用取色等视为修改；文本值只说明已修改，不暴露密钥。 |
| 12 | 实例快捷入口 | 提供入口；点击执行 | 实例菜单 → 文件与存档 | 按真实隔离设置打开已有目录；桌面快捷方式明确为实例文件夹，不声称直接启动游戏。 |
| 13 | 长任务进度说明 | 执行中显示 | 下载面板任务行及右键说明 | 显示阶段/用时；仅在有单位、总量和足够样本时估算本阶段剩余时间，不虚构整个安装进度。 |

| 16 | 截图浏览 | 提供入口，主动打开 | 实例菜单 → 文件与存档 → 浏览截图 | 当前实际游戏目录的缩略图、原图、导出和确认删除；不扫描其他目录或上传。 |
| 17 | 服务器地址隐私 | 默认保留现有显示，用户开启 | 设置 → 使用习惯与隐私 → 隐藏服务器地址 | 地址栏和提示文本遮挡；明确复制仍复制真实连接地址，任意自填名称不做内容识别。 |
| 18 | 窗口位置恢复 | 默认开启，可关闭 | 设置 → 使用习惯与隐私 | 记住正常尺寸和显示器，断开屏幕后回到可见工作区；最小化时不意外还原；CLI尺寸本次优先且不写回。 |

## 已执行的验证

- 修改前先检查原始源码基线，后续重复执行全项目 XAML、资源字典、命名、事件接线、项目包含和源码契约检查。
- 设置搜索/重置/修改摘要的专用 Python 静态检查；搜索目录索引生成与校验；旧预览导航、Debug 快捷键接线检查。
- 对新增弹窗、下载/备份生命周期、配置草稿同步和权限默认值做交叉源码复核。发现并修复备份锁、确认框临时卸载、队列结果误记、加载器误判与小窗口裁切等问题。
- 原压缩包逐文件对比，保留全部原始文件，检查归档CRC和所有更新文件字节一致。
- 新增 C# 回归项目与断言属于**待执行**，不是已通过的运行测试。既有预览交互 AST 脚本因缺少 `tree_sitter` / `tree_sitter_c_sharp` 依赖未运行，已明确记录为跳过。完整静态报告见 `Tests/Ux30Validation/`。

## Windows 自动检查

安装 .NET 8 SDK 后，在桌面空闲时执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Tests\Test-Ux30.ps1
```

脚本构建 WPF 主程序并运行 `Tests` 下全部回归程序，包含现有的输入交互测试（可能短暂移动鼠标）。实际失败退出码会被保留，结果写入 `Tests/ux30-windows-results.json`；不会把界面验收标成通过。首次还原依赖需要可用的 NuGet 网络。`-SkipRegression` 仅构建并明确记录跳过，不表示所有测试通过。

## 界面与功能验收清单

建议在测试实例和副本存档中逐项执行；运行测试本身不应替换真实用户的实例或覆盖存档。

1. 在 854×480、1000×640、最大化下，分别以100%、125%、150%、200%缩放查看默认/浅色/深色主题。检查新增弹窗、设置、账户、下载、实例、模组和服务端页面：按钮保持整块单行、文字不重叠、低频菜单不常驻、长内容能滚动到关闭/确认按钮。
2. 用 Tab / Shift+Tab、Enter、Esc、Shift+F10 检查焦点、菜单、返回与复制；用触屏长按查看长名称，滑动列表时不应误弹提示。
3. 设置搜索命中折叠项、上下导航、清空；修改/还原同一值、滚动/展开/切页；验证只有实际编辑触发摘要与保存提示。分别在手动保存、自动保存和撤销模式验证135项绑定中代表性的文本、枚举、滑块与分组重置。
4. 在设置存在其他未保存编辑时，从下载菜单改限速、任务记录页关记录、全部工具开记录；回设置保存与撤销，确认显式修改被保留、无关草稿不丢。布局恢复应保留未保存的透明度等其他设置。
5. 建立两个不同目录但同名实例，分别收藏/加备注/改图标、切筛选并返回；确认互不影响。最近实例/工具/服务端记录默认不增长，开启后只记成功操作，关闭及清空有效。
6. 打开启动摘要，确认显示的账号、隔离目录、Java候选和内存对应当前配置；无新增进程/联网/设置文件。分别用过期、未知、可刷新、本地有效的缓存账号检查文案；实际启动仍通过原账户校验。
7. 下载并发设为1，用多个测试任务检查等待顺序、上下移、失败重试、暂停/恢复、取消与移除。重启后只支持恢复的原版安装保持暂停。验证阶段单位、无法估算时不显示虚假ETA，以及运行库不可中断阶段仍受保护。
8. 低限速下使用大于限速桶容量的文件，确认能够完成且可取消；切换限速立即生效。游戏中降速关闭时不额外发现进程，开启后分别检查Java/基岩版并退出恢复。
9. 取消/暂停下载后，检查保留说明与真实文件相符；确认清理只针对记录的`.part`，有执行中的任务时拒绝清理，完整文件与其他实例不受影响；磁盘不足报出明确原因。
10. 使用Fabric/Quilt/Forge/NeoForge各一测试模组集（缺依赖、未知范围、含嵌套模块），检查本地预览只作建议；关闭手动联网检查后不会发起该检查，原有自动模组通知偏好不变。更新选择框的版本、适配范围、依赖、说明与来源响应一致。
11. 游戏运行时拒绝存档备份；退出后手动备份、检查原文件与归档哈希、恢复副本并进游戏确认。测试损坏/路径越界/符号链接/空间不足/取消，确认不覆盖原存档。自动备份默认无定时器，开启后只备份已选存档并只清理超出保留数的自动备份。
12. 截图浏览确认按实际隔离目录读取；导出、取消删除、确认删除、文件被外部修改后拒绝操作。不存在截图目录时不自动创建。
13. 诊断预览输入令牌、Cookie、中文用户名字段、带密码/查询串的URL和用户路径；检查脱敏、选择项与ZIP内容完全一致。错误复制不含原始密钥；分享前仍需人工核对任意自定义日志内容。
14. 开关服务器地址隐藏，检查界面和悬停提示不泄漏地址；普通复制仅地址，含密码复制必须确认。收藏、筛选和最近服务端仅作用于所选ID。
15. 多显示器/不同DPI间移动窗口，退出恢复、拔掉显示器、最小化状态拔屏；窗口可见且不抢焦点。带`--window-size`运行后，不应覆盖上次保存的几何信息。
16. 检查已有 Agent/Plan、纯聊天、权限、动态内存、旧版1.0启动、统一下载、搜索框透明度、预览导航及`--debug`/F3行为，避免回归。每项实机结果记录为通过/失败/跳过，并保留失败复现步骤。
