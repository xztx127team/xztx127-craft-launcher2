# 界面、搜索与日志审计修复接入清单

| 问题 | 实际生产接入 | 验证覆盖 |
|---|---|---|
| 跨分类取消搜索后保留加载中 | 三类搜索记录实际显示页；取消统一恢复页码、实际数量、翻页按钮及重新搜索入口；旧请求不能覆盖新状态 | ExperienceSearchRegression：首次取消、已有页取消、最后一页取消 |
| 多实例日志混入其他进程 | 每个订阅捕获来源及代次，取消订阅时递增代次；UI执行时同时核对来源、代次、当前选择及Loaded状态 | LogViewProjectionRegression：当前源接受、旧源/旧代次/已卸载拒绝 |
| 大量日志产生过多UI排队及逐行完整快照 | 有界待显示文本、至多一个待执行UI回调；整批追加，完整进程快照仅在切换/刷新时取得 | Windows需验证噪声输出与快速切换；不声称已实机验证 |
| 启动器会话内存无上限及空轮询全量复制 | BoundedLogBuffer最大1Mi字符，旧前缀分块暂存；退出时保序合并完整会话文件。修订号未变化时不构造新字符串，日志页不重复投影 | LauncherLogBufferRegression链接实际服务，覆盖缓存上限、超长行、空轮询、完整文件无丢行/重复 |
| 统一单位间距开关接入不完整 | 公共FormatCapacity主单位及精确字节数均遵守开关，开为不换行空格、关为普通空格 | PresentationPreferencesRegression验证两种配置 |
| Overlay内Esc撤销被关闭抢先处理 | InputExperienceService.TryHandleEscapeEdit由全局Esc在关闭弹窗前调用；保守跳过敏感/命令/未知输入及搜索框 | Windows需验证普通文本首次Esc撤销、再次Esc退出、敏感输入保留原样 |
| 搜索历史/组合嵌套null导致异常 | ExperienceSearchState.Normalize修复集合、空行、Values及字符串；菜单展示与保存入口自身调用，不依赖ConfigService初始化 | ExperienceSearchRegression导入null行、Values=null及保存覆盖 |
| 动态内存非法百分比、倒置范围静默回落 | 保存前校验0.1–100有限百分比及上下限顺序；读取与校验使用同一解析策略；MB范围同样拒绝倒置 | InputExperienceRegression文化区域、非法/非有限/范围/倒置输入 |

当前环境缺少.NET SDK和Windows/WPF运行时，新增或扩展的C#行为回归尚未执行，Windows交互测试也未执行。可在.NET 8 SDK环境运行各回归项目，并由统一Tests/Test-Ux30.ps1执行主程序构建及独立测试。静态检查数量会随并行整合变动，以最终交付记录为准。
