# 诊断、截图与任务结果

- 「日志」页右上角「更多」包含诊断导出与本次任务结果。各日志工具栏只常驻进程/文件选择、刷新或扫描、复制；AI 分析、清屏、独立窗口放在当前日志的「更多」菜单。
- 导出诊断先生成不可变的脱敏预览，勾选内容后才另存 ZIP。保存与预览使用同一份文字，不会在保存时重新加入未选择内容，不会自动上传。只取有限的会话末尾、当前游戏输出、已选崩溃报告及启动器异常日志；崩溃弹窗只加入本次启动时段的日志文件。不会扫描账号文件或整份配置。
- 常见登录令牌、API 密钥、HTTP 凭据、Cookie、URL 查询参数、邮箱、用户名和用户主目录会在本地隐藏；包括启动器的中文「账户=」日志。自动脱敏不能识别所有个人信息，分享前仍需检查预览。为避免半截令牌泄露，读取大日志末尾时丢弃被截断的第一行。
- 通用错误框提供稳定分类编号及「复制说明」；友好错误对话框将技术详情默认折叠。复制内容默认脱敏。崩溃弹窗的导出、记事本与运行库修复入口放在「日志与修复」菜单。
- 实例的「查看截图」仅浏览实际游戏目录 screenshots 下的 PNG/JPEG，最多显示 400 张（单次最多检查 5000 个文件），每张不超过 40 MB；图片解码在后台并限制缩略图尺寸。损坏图片保留文件名。打开、导出、删除均需主动操作；永久删除再次确认，且拒绝操作已变化或越出当前目录的文件。
- 任务结果默认只保留本次会话最近 100 条类型、时间与结果，不采集任务名称、路径、完整命令、聊天或凭据，也不写到磁盘。可关闭并清空；重新启动后清空。显示包括已接入的下载/安装、模组更新和备份/恢复任务。
- 服务器卡片「更多」可收藏。列表「筛选与更多」可查看全部、收藏、最近启动；最近服务器记录默认关闭，开启后最多保留 12 个成功启动的实例 ID，可随时清空或关闭。服务器地址隐私显示跟随设置；普通复制只复制游戏连接地址，不附加 URL 身份信息或密码。右键复制按钮可显式选择含管理密码的 RCON 信息，需再次确认，不写入日志或历史。

## 验证范围

编辑环境未安装 .NET SDK，且不能运行 Windows WPF。已进行 XAML、事件处理器、资源与项目依赖静态检查，以及从生产代码提取脱敏表达式的等价规则样例检查。`Tests/DiagnosticPrivacyRegression` 提供链接真实服务的 .NET 8 回归用例，尚未在此环境执行。

Windows 验收应检查：854×480 和缩放后的各弹窗不裁切；深浅主题；长文件名；取消/确认删除后返回父弹窗不重复加载；复制错误和隐藏服务器地址；ZIP 所选内容与预览完全一致；关闭结果记录不再新增；最近服务器默认关闭；修改截图后旧操作被拒绝；损坏和超大图片不会阻断其余文件。
