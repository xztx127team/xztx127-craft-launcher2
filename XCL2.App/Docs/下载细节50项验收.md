# 下载细节（候选 21–30）

新增便利工具都收在现有下载列表“管理”或任务右键菜单；首页不添加按钮。

| 项 | 实现与默认值 | Windows 验收 |
|---|---|---|
| 21 安全暂停全部 | 管理菜单手动操作；处理 CanPause 的运行任务，并先暂停 SupportsPause=true 的等待项，防止调度器立即开始下一项；不可暂停安装不受影响 | 同时下载文件、等待任务、运行不可中断安装，暂停全部后仅可暂停的运行与等待任务变为已暂停 |
| 22 勾选取消等待 | 主动打开选择界面、勾选、明确确认；执行前重新核对仍在等待 | 等待任务在确认前开始运行时不被本批次取消；原文件保留 |
| 23 真实重试倒计时 | 默认开启，显示下载器原有退避等待，未增加等待 | 断网触发 0.3–0.7 秒既有重试，详情显示真实短倒计时，等待结束立即消失；普通连接等待不虚构重试 |
| 24 阶段细节 | 默认开启，详情按同时进行的实际连接、连接槽位等待、传输、校验和限速等待统计 | 并发文件与分片显示计数，阶段 scope 完成后消失；没有接入的流程不编造阶段 |
| 25 安静时段 | 默认关闭；中央设置“下载细节”选择本地 HH:mm，支持跨午夜；相同起止为全天 | 原先不提醒仍不提醒；允许提醒的完成事件在时段内仅进右下角角标，时段外遵循旧配置；模组更新设置不修改 |
| 26 发起来源 | 默认在任务详情显示；内部文件名映射成页面名称，不把源码路径暴露在界面 | 下载中心、基岩版、服务器等任务显示相应来源；未知调用显示启动器任务；恢复任务明确标为下载中心上次任务 |
| 27 定位完成文件 | 完成任务详情手动定位实际被记录且仍存在的文件；本会话最近完成上限 20 项，每任务最多 100 路径 | 完成行自动收起后仍可从管理菜单打开；点击定位时复查存在；已被安装器删除的下载文件不提供假入口 |
| 28 个人备注 | 详情手动保存，最多 200 字，仅保留本会话任务，不重命名文件 | 修改备注不影响队列任务名、实际下载路径或文件名，移除任务/退出后不承诺保留 |
| 29 速度曲线 | 默认关闭，中央设置开启；只在下载面板打开时按真实观测字节采样，关闭即清空，最多 60 点 | 新传输前显示等待真实数据；不是文件数假冒 MB/s；关闭面板后计时器停止，重新打开不回填历史 |
| 30 磁盘可用空间 | 详情手动刷新读取实际目标磁盘 AvailableFreeSpace | 显示查询时间；未提供目标路径或不可访问给出原因；不宣称这是完整安装所需空间 |

支持真实传输阶段与字节观测的路径是原版 DownloadService 和统一 DownloadEndpoints（包括接入它的通用下载、运行环境与资源下载）；外部安装程序的下载/安装子进程不伪造字节速度。

完成文件、备注和最近完成列表仅在内存保留，不增加磁盘操作历史。下载中断恢复仍只恢复原有已明确支持的原版任务，不新增自动执行。

源码检查不能代替 Windows 上的真实网络、安装器和 WPF 交互验收。项目内 DownloadQueueRegression 增加上述核心边界的 C# 测试源码，本次环境无 .NET SDK，未执行。
