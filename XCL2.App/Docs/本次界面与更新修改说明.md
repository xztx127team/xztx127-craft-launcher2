# AI 界面、会话与更新设置修改说明

本次修改基于上传的 2.2.22 纯源码，继续采用 WPF 和现有服务，不新增运行依赖。

## 功能

- 发送按钮右边新增小圆圈，以输入加已输出 token / 上下文上限显示占用比例；超过 90% 使用警示颜色。输出预留上限在详情中单独显示。
- 鼠标悬停打开用量详情，点击可固定，Esc 或点击外部关闭。详情包含上下文限额、缓存命中率、会话累计 token、USD 估计成本、模型本地 token 配额及美元预算。短屏幕支持滚动。
- 上下文上限、价格或供应商缓存字段未知时显示提示；限额与价格使用已有模型设置，不推测服务商账户余额。
- 模型下方新增“当前任务”横条，接入源码已有的 WorkTask 规划 / 执行任务。选择运行任务恢复原会话，选择其他已保存任务打开对应会话或从断点创建续做会话；选择本身不会发送消息。可在 AI 设置中关闭，并支持设置保存和导入 / 导出。
- 当前会话运行时点击“新对话”：选“是”取消当前请求、完成保存后新建；选“否”后台保留当前请求并新建；选“取消”保持当前会话。
- 会话的取消令牌、流式气泡、输入草稿与问答卡片分别保存。历史标记运行中，可切回继续查看、回答问题或停止任务。后台提问会等待用户切回作答。
- 设置页新增“检查更新”，复用既有 GitHub Releases API 与下载替换流程。发现新版本后由用户选择是否安装；区分网络失败、版本最新、更新关闭及已有检查运行等状态。
- 设置可分别关闭“启动时检查启动器更新”和“允许下载安装启动器更新”。关闭安装后手动按钮仍可查询最新版本。启动器原有的开机自启动开关继续可用。

## 验证情况

已做修改文件的 XML 解析、XAML 名称与事件方法核对，以及代码静态交叉审查。源码包保留原始文件并通过 ZIP 完整性检查。

当前环境没有 .NET SDK 或 Windows WPF 运行时，**未执行 C# 编译、C# 回归测试或真实界面 / 更新安装测试**。以下命令供 Windows 上安装 .NET 8 SDK 后验证。在 `XCL2.App` 目录执行：

```powershell
dotnet run --project Tests/AiUsageRegression/AiUsageRegression.csproj
dotnet run --project Tests/AiHttpRegression/AiHttpRegression.csproj
dotnet run --project Tests/LauncherUpdateRegression/LauncherUpdateRegression.csproj
dotnet build XCL2.App.csproj -c Release
```

用量回归新增实际占用与预留输出的区分、未知上限、满容量边界、任务栏配置兼容等案例；HTTP 回归新增双会话独立问答、分别完成保存及取消隔离案例；更新回归覆盖版本归一化、架构选择与开关 / 确认策略。

## Windows 验收步骤

1. 为模型设置上下文上限和价格，发送请求；检查发送按钮右侧圆圈、悬停、点击固定、Esc 关闭和详情字段。缺失缓存或价格时应显示未知。
2. 创建两个任务，确认横条可切换对应会话且不自动发送；关闭任务栏设置并保存，再打开设置确认开关保留。
3. 运行一个长请求，分别验证新对话“取消”“否”“是”。“否”后可在新会话发送请求，并从历史返回旧会话停止；旧回复不能进入新会话。等待提问时使用卡片上的“停止任务”。
4. 关闭启动检查并保存后重启，确认不自动检查，手动按钮仍可用。关闭更新安装后检查版本，确认不会下载或替换程序。
5. 允许更新时检查，分别取消和选择更新；确认网络失败不会被误报为最新，下载期间关闭更新开关应保留当前版本。实际替换 / 重启请在测试副本上验收。

会话保存失败时会显示错误并暂留当前进程内存；恢复磁盘权限后应重新保存，内存内容不能跨进程恢复。
