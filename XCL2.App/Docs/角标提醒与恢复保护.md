# 角标提醒与恢复保护

建议类提醒只增加右下角“提醒”角标。点击后展开收件箱，可查看、忽略或清空已读；不会因发布建议自动导航、打开网页、下载、恢复文件或关闭游戏。后台启动器更新、离线账户建议、低内存建议和游戏异常退出诊断已接入。低内存提醒的“查看当前内存”会重新采样，旧提醒不会据此关闭任何进程。

用户主动操作时的必要确认与错误反馈继续保留；现有模组更新的检查、选择清单及提醒方式未被改写。手动更新检查仍可独立于“启动时自动检查”执行。AI 工作模式、鼠标键盘与 Shell 权限保持用户原有选择，没有放宽授权。

设置新增“提醒、启动检查与恢复”，按正常保存 / 自动保存 / 回退规则生效：

| 项目 | 新增默认值 |
| --- | --- |
| 右下角提醒角标 | 开启；也可在设置中手动查看收件箱 |
| 启动前实例完整性检查 | 开启；未选择模式时采用轻量模式，原有严格模式选择保留 |
| 可恢复下载任务记录 | 开启；恢复后暂停，需手动继续 |
| 模组 / 资源包更新前快照 | 开启；默认保留 10 份，总空间上限 1024 MB |

启动完整性检查已移到后台，初次启动不再弹出检查模式选择窗口。发现缺失文件仍由用户决定是否补全；不自动修改 Java、内存设置或删除文件。现有 JVM 参数诊断、崩溃证据分析与 AI 编辑备份继续复用。

下载恢复目前接入下载中心的原版安装任务。保留公开 HTTPS 清单与已配置目录等重建任务所需的信息，不保存带凭据、查询参数或片段的链接；不恢复 Shell、系统安装进程、插件回调、加载器安装或任意函数。重启后只登记到统一下载管理；点击继续后复用已有通过校验的文件，并沿用原下载器的续传与校验。服务器不支持续传时从头下载。多开启动器使用独立会话记录和独占锁，避免把其他仍在运行的会话误认为已中断。访客启动不导入普通会话的下载记录。

模组更新的新文件先按发布清单的哈希和大小校验，再原子替换；原有禁用状态保留。每次更新前保存受影响的旧文件与目标位置，未选中的模组不参与修改。恢复前验证全部备份与现有文件，发现后续编辑就停止；同一实例的游戏仍在运行时不恢复。恢复仅由设置中的“查看更新快照”或用户点击角标入口后确认执行。旧的已完成快照按保留数量与空间轮换；未完成快照保留核对，不自动删除。若更新过程中断电，处于“未完成”的快照不直接自动写回，可打开目录人工核对原文件。

AI 文件编辑已经使用持久化完整字节备份、预览与带冲突检查的回滚，本轮没有再复制一套，也没有宣称可撤销任意 Shell 指令。

验证：新增 `RecoverySafetyRegression`，扩展 `DownloadQueueRegression`；静态检查覆盖 XAML 名称和事件、独立测试的生产源码依赖。当前环境没有 .NET SDK 或 Windows 桌面，C# 测试、实际下载与恢复交互尚未运行。Windows 验收时应检查：后台建议只增角标；旧模组提醒偏好保留；重启后下载暂停；手动继续及移除记录；模组更新前快照、禁用状态、校验失败保留旧文件；后续编辑与正在运行的游戏阻止恢复；设置保存、撤销和自动保存回退。
