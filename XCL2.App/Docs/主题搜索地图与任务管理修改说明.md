# 主题、搜索框、地图与任务管理修改说明

本轮在上一版 AI 界面与更新设置源码上继续修改，保留此前的上下文圆圈、并行会话及更新功能。

## 镜像列表主题

下载镜像管理表格的表头、空白区域、交替行、选中状态、文本编辑框及复选框均使用主题资源。切换明暗或自定义主题时，颜色随主题更新。保留列排序、列宽调整和原有保存校验。

## 搜索框布局编辑

默认悬浮搜索入口向下移动 5 个 WPF 像素（原顶部偏移 −7 改为 −2）。

在设置的“外观与视觉效果”中开启“编辑搜索框”：边缘拖动调整大小，按住中央 500 毫秒再拖动改变位置。短按和提前移动不会触发搜索；Esc、鼠标捕获丢失、窗口布局变化会取消本次拖动并恢复起始布局。

也可直接调整宽度、高度、水平 / 垂直偏移和不透明度，或重置布局。宽度 160–720、高度 28–120、不透明度 20–100%；实际显示会限制在可见区域内。两种搜索入口样式始终使用用户设置的不透明度，鼠标悬停、点击和搜索弹层开关不再将入口强制改为 100%。

修改使用设置预览，遵循正常保存、自动保存、撤销与离页处理；编辑模式本身不保存。关闭入口后不留额外顶部空白，Ctrl+K 仍可搜索。

## 二维地图

存档页面新增“二维地图”标签，读取本地已生成的 Java Anvil 区块：

- 主世界、下界、末地以及存档中的自定义维度。
- 选择中心坐标和 8–256 方块半径的正方形范围。
- 地表方块颜色图、高度图、区块网格；滚轮缩放、鼠标拖动平移和适应窗口。
- 悬停显示 X / Y / Z 和表面方块；定位出生点和 level.dat 中的单人玩家位置。
- 导出 PNG：每方块一像素，导出所选范围的地表图，不含定位标记和网格。

保留原来的世界设置、结构投影和 NBT 标签（地图为第 4 个标签）。预览只读取已有区块，不生成或修改地形。未生成区域、空区块、无法读取区块分别展示，并支持取消及切换存档时防止旧结果覆盖新选择。

解析覆盖 Java 1.13+ 常见调色板及连续 / 填充 packed-long 格式、gzip / zlib / raw 压缩；1.12 及更早数字方块格式、外置 .mcc 区块和 LZ4 压缩目前显示不支持。下界展示最上层屋顶。颜色是方块类别示意，不能代替游戏材质或实际游戏内渲染。设置单区块 8 MiB 和每次预览 256 MiB 解压限制，损坏区块也计入总量。

## 非任务与已完成任务

“任务步骤与断点”中新增“设为非任务 / 设为任务”。非任务聊天不会自动建任务或保存任务步骤；显式设为任务后，下一次发送才开始新任务。当前生成期间先停止或等待完成再切换。

新增“已完成任务”入口，可查看步骤、证据、备注，打开关联对话或确认删除。删除只移除任务记录和关联，保留聊天、token 用量与文件变更历史。关联对话仍在生成时拒绝删除。

已完成任务从当前任务选择列表移出；再次打开后保持为普通聊天，继续发送不会把旧任务恢复为运行中。需要新任务时显式点击“设为任务”。缺失或损坏的任务记录不会隐藏原聊天历史。
