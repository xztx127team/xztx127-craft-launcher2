# 彩蛋码与关闭入口

在“设置 → 体验细节 → 趣味与彩蛋”中，点击“输入彩蛋码”并验证成功后，会打开关闭愚人节菜单的确认窗口。取消勾选“允许愚人节彩蛋”则直接打开普通挑战窗口。

- 未输入有效彩蛋码时，按窗口提示完成 7 道文字题、8 个小游戏和本地人机验证后，再确认关闭。
- 输入 `跳过` 或 `xztx127` 后，本次打开的窗口会提供直接关闭入口，无需完成文字游戏、闯关或人机验证。
- 彩蛋码只解锁当前窗口。关闭或取消窗口后，再次打开仍需重新输入；无效代码不会解锁。
- 点击小白旗直接结束当天整蛊，不进入文字游戏或闯关。F1 也保留直接结束当天整蛊的行为。

通过关闭确认后会立即停止当天整蛊。关闭总开关的更改仍遵循设置页当前的手动或自动保存规则；使用手动保存时，需要点击“保存设置”才能持久保存。

## Windows 验收

1. 在设置中取消勾选总开关，确认会弹出挑战；取消窗口后，总开关保持开启。
2. 分别输入两种有效代码，确认可直接关闭；输入无效代码时仍需挑战。
3. 取消并重新打开窗口，确认上次的彩蛋码不会沿用。
4. 不输入代码，完成全部挑战后确认能正常关闭。
5. 在整蛊期间点击小白旗，确认立即结束且不弹出挑战；再验证 F1。
6. 搜索“输入彩蛋码”，确认结果定位并展开设置中的“趣味与彩蛋”区域。
