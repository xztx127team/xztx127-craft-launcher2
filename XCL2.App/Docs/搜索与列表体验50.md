# 体验补充：搜索与列表（候选清单 1–10）

## 默认与入口

在“体验细节”中的“搜索与列表”分组可控制中文输入等待、多词匹配、命中文字、筛选标签、Esc 分层、稳定排序及加载数量，默认开启。保存筛选组合、搜索历史默认关闭。

历史和组合只出现在搜索框的右键菜单，不增加首页按钮；历史支持填回、逐条删除、全部清空。组合支持保存当前筛选、应用和逐条删除。历史最多 20 条，组合最多 10 条，跨范围保存且不上传。

关闭历史后不再添加、不显示旧条目，已有记录保留，便于重新打开后由用户手动清空。组合关闭后不读取、不应用。输入文字、浏览列表不因此写入配置；只有主动提交搜索、选择结果、保存或删除才写入。

## 实际接入

1. 功能搜索和下载中心的本地/在线筛选输入均等待输入法组成结束。候选窗操作的 Esc/Enter 交给输入法；组合过程不会发起新搜索。在线请求取消并按序列号丢弃旧结果。
2. 功能目录与本地游戏版本清单支持空白分词、全词同时命中，兼容全角和大小写；在线搜索仍采用服务本身的语义。
3. 功能搜索结果标题和本地版本名称用同一组 Run 轻量强调命中文字，不叠加阴影或第二份文本。Unicode 长度变化会映射回原始文本位置。
4. 下载中心的非空名称/版本、非默认来源/分类/加载器及预览开关显示可单独取消的标签。标签只出现在对应筛选栏下方，整块标签换行，按钮文字不逐字换行。
5. 功能搜索 Esc 先关闭范围选择器，再收起结果建议、清空文字、最后关闭搜索卡；普通搜索框 Esc 清空当前搜索。输入法组成中不接管。
6. 功能目录、原版版本、模组、社区资源和地图各自保存筛选组合；应用不会触发插件选择器或执行下载。
7. 同样范围支持本地历史，自动防抖搜索不写历史，主动搜索/Enter 或选择功能结果才写。
8. 表格在列标题右键菜单中提供“显示的列”和“恢复默认列”，保留原菜单；具名表格按所属页面和列的稳定标识保存。至少保留一列，行内右键菜单不受影响。
9. 本地版本清单右键提供发布时间新/旧顺序、名称正/倒序，勾选当前方向，分页摘要同步显示方向，同值保持原集合顺序。默认保持既有发布时间倒序、ID 次序；关闭增强则回到默认顺序。额外只对本地、只读、非分组的 ListCollectionView 表格接管简单属性排序，箭头显示方向；编辑表格、远程/复杂路径、已有自定义比较器的视图保持原逻辑。
10. 在线列表显示“本页已加载 N 条”，不将两个来源的重叠总数相加；“加载下一页”只有点击才发起请求，继续沿用原有分页，不后台预抓取。

## 验收

`Tests/ExperienceSearchRegression` 链接实际纯逻辑，检查默认关闭、保留上限、去重、范围隔离、快照副本、多词/Unicode匹配、命中范围、双来源数量语义。

Windows 必验：微软拼音候选选择/取消；候选窗 Esc 不清空正文；快速改词/切来源不显示旧结果；搜索弹层三级 Esc；窄窗口/125%和200%缩放下标签及分页按钮；表格列菜单的首次右键、默认恢复、至少一列、升降序同值顺序；关闭历史后不增加记录；重新开启后逐条删除/全部清空。

本次环境没有 .NET SDK 与 Windows WPF，C# 回归、编译和实机交互不能在此环境执行。XML 和源代码检查不能代替这些验收。
