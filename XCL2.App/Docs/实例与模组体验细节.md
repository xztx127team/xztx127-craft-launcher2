# 实例与模组体验细节（候选清单 31—40）

入口保持在实例右键菜单、模组页面“更多”菜单及相关操作时，默认不新增首页工具条。

| 项目 | 实际入口 | 默认与关闭 |
|---|---|---|
| 31 环境摘要 | 实例右键 → 文件与存档 → 复制环境摘要 | 手动；摘要只包含游戏/加载器版本、隔离状态和模组数量，不含实例自定义名称、账号、路径、Java参数。 |
| 32 共享目录 | 实例列表的小型“共享游戏目录”标记 | 开；只有至少两个实际实例的有效游戏目录相同才显示。设置 → 体验细节 → 实例与模组细节可关。 |
| 33 后台任务归属 | 实例列表顶部的一行说明 | 开；只在其他实例确有运行、等待或暂停任务时显示。可关闭“切换实例后的后台任务归属”。 |
| 34 导入预览 | 文件夹/ZIP实例、整合包导入及快速向导，在写入前显示 | 开；显示目标、预计内容文件数、同名冲突。扫描不解压、不建目录、不联网，不跟随符号链接，最多十万条、清单4MB。可关闭“导入前预览”，原有导入校验继续有效。游戏本体/加载器联网安装数量不计入内容文件数。 |
| 35 同名区分 | 模组页和快速向导的游戏文件夹选择器 | 开；只有同名文件夹才追加目录信息；实例选择先按文件夹分组，不把不同目录同名实例混为同一项。可关闭“同名文件夹显示所属目录”。 |
| 36 重命名预览 | 实例重命名确认后、真正改名前 | 开；显示旧名、新名、目标目录。可关闭“实例重命名前预览”。 |
| 37 批量模组摘要 | 模组 → 更多 → 筛选与批量启停 → 勾选 → 批量操作 | 开；显示已有启用/禁用数量、实际变更数、保持数和隐藏选择数。可关闭数量摘要；启停始终由用户点击，不删除文件。 |
| 38 隐藏的已选项目 | 模组筛选区下方 | 开；筛选保留已选项目，显示隐藏数量。可关闭提示；批量摘要仍准确包含全部选中项。 |
| 39 缓存资料时间 | 手动检查更新后的模组页说明、更多 → 查看上次检查资料 | 开；只缓存本次会话最近20个游戏目录、每个最多1000个候选。资料显示获取时间，并明确只读；无法从缓存直接升级。可关闭页面缓存时间显示。不增加后台联网。 |
| 40 忽略指定更新版本 | 更新选择弹窗 → 忽略此版本；模组更多 → 已忽略的更新版本 → 恢复提醒 | 手动；按实际游戏目录、项目、精确版本标识保存规则，后续版本仍显示。恢复后手动重新检查。不会改变已有自动通知或手动联网检查偏好。 |

补充：实例内存输入和全局一致，支持可选的MB/GB单位解析。无效输入先提示再返回，不会把一半设置写入；最小值大于最大值也会明确说明。

## 验证范围

新增 `Tests/InstanceExperienceRegression` 为纯服务回归用例。当前环境没有.NET SDK，也不能运行Windows WPF，C#编译和实机UI验证尚未执行。静态XML解析通过不代表程序已编译或所有界面已实际显示。

Windows应验证：854×480及高DPI下按钮不逐字换行；浅/深主题无新增阴影重影；无后台任务时不出现归属行；单实例不显示共享标记；切换目录后选择清空；筛选隐藏选择后批量摘要正确；取消预览不产生目标目录；忽略当前版本后新版本仍可见；恢复规则后可重新检查；缓存对话框不能安装。
