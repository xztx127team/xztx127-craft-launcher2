# 展示、键盘与布局体验

这些改动默认提供方便入口；次要工具仅在所属页面、右键菜单或明确的空状态中出现。没有添加新的常驻主窗口按钮或全局阴影层。

## 默认值与范围

- 键盘焦点使用单层细描边；按钮保留系统 Enter/Space/Tab 行为。下载中心资源、模组、地图列表选中行按 Enter 打开详情；焦点在行内按钮时保留按钮自身行为。
- 减少动画默认跟随系统“在 Windows 中显示动画”设置。用户可在设置中关闭跟随；启动参数禁用动画仍优先。
- 服务器地址隐私显示默认关闭。开启后只遮挡展示文字，真实连接与用户主动复制仍读取原值。
- 记住窗口位置默认开启。保存显示器、正常窗口尺寸与相对位置；显示器断开时移到可用工作区。命令行临时窗口尺寸不读取或写回位置记录。
- 时间默认跟随系统区域格式与本地时区，可选12/24小时；容量默认自动MB/GB，可选固定单位与精确字节。悬浮性能面板等已经有独立单位的功能保留其独立设置。
- 首页只在未选择实例时显示小型操作引导。下载中心无结果时，在列表区域显示清除筛选或重试入口；不会因没有搜索结果而弹窗。
- 工具收藏在百宝箱“全部工具”的筛选中查看，右键条目收藏/取消；固定工具排序保持原设置。工具最近使用记录默认关闭，用户开启后最多保留12项；关闭后不追加，清除菜单可删除已有记录，访客会话不追加。
- 布局重置仅由用户主动触发，恢复窗口、下载面板与搜索框尺寸位置；不会改动功能权限、账号、实例、主题或搜索框透明度。

## Windows 交互验收清单

以下是必须在 Windows 上执行的交互场景，不能用静态检查代替：

1. 最小窗口854×480、默认1000×640、最大化和125%/150%/200%缩放下，检查首页、下载中心、百宝箱。按钮标题不拆成逐字换行，主/次按钮间距一致，工具栏不足时单行滚动，正文可按需要换行。
2. 仅用Tab/Shift+Tab、Enter、Space操作首页按钮、输入框、下载结果及百宝箱搜索/筛选。焦点轮廓清晰；下拉框方向键不被外层搜索拦截；焦点不会同时出现多层阴影。
3. 系统关闭动画后，窗口/页面/弹窗转为静态显示；重新开启后恢复用户各动画强度。`--reduced-motion` 临时参数仍优先，配置不被改写。
4. 下载搜索无结果、来源部分失败、全部失败、快速连续筛选时，只显示当前查询状态。清除筛选需点击；不自动下载。用户主动搜索的来源警告进入右下角提醒收件箱。
5. 服务器地址隐私开关切换后当前页面即时遮挡/恢复；悬停提示及自动化可访问名称也不泄露地址；主动复制内容和真实连接仍正确。
6. 双屏窗口分别靠近四边关闭后重开；不同DPI显示器之间移动；拔掉原屏幕后重开/还原最大化窗口。标题栏可访问，窗口不落到不可见区域。
7. `--window-size 1280x800` 启动后退出，下一次无参数启动仍使用之前保存位置；临时参数不覆写记录。
8. 百宝箱右键收藏一个工具，切“我的收藏”可打开；取消后消失。默认关闭记录时打开工具不追加；开启后按最近顺序、去重、最多12项；清除后不恢复。
9. 改时间制、容量单位后，新旧显示项刷新一致；MB/GB换算准确，非空小文件不显示为零；精确字节只有开启后出现。
10. 明确点击恢复布局后，搜索框与下载面板恢复合理尺寸；透明度、权限、账号、实例和主题保持原值。
