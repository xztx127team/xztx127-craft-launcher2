# 整合包与实例导入导出修复

| 问题 | 修改后的行为 | 验收方式 |
|---|---|---|
| 覆盖导出失败后原包消失 | 先完成内容复制与压缩，再将同目录临时 ZIP 替换到最终路径；压缩或提交失败保留旧目标 | 已有目标包 + 空内容、复制异常、磁盘不足；核对旧包哈希及临时文件清理 |
| ZIP 同前缀目录越界、链接或联接写入 | 实际底层导入检查每个 ZIP 路径和目标祖先；拒绝 `..`、ADS、设备名、ZIP 符号链接及目标 reparse；与可选预览开关无关 | 直接调用 Import，关闭预览，通过服务器导入及客户端导入分别尝试恶意样本 |
| 快速向导误把内容导入视为完整安装 | 从清单安装游戏本体、声明加载器、版本描述和整合包内容，保存安装器实际返回 ID 并启用实例隔离；无版本或不支持加载器时拒绝 | 空游戏目录导入正常 xclpack / mrpack；确认版本 JSON、本体/继承版本、加载器和 mods/config；再实际启动 |
| xclpack 元数据名不匹配 | 完整安装器识别真实 `xclpack.json`，兼容旧 `xcl2-modpack.json` | 本启动器导出后，在空目录重新导入 |
| 复制版本时其他 JSON 覆盖主描述 | 只重命名来源版本 ID 对应的主 JSON/JAR，辅助 JSON 保留原名；不删除可能被其他实例使用的加载器来源目录 | 来源版本同时放主描述和辅助 JSON，核对新实例主类和继承字段 |
| 服务端错误使用客户端 mrpack 内容 | 服务器导入按 `env.server` 筛选，公共 overrides 后应用 server-overrides；客户端维持 client 分支 | 包含 client-only、server-only、公共及端侧同名覆盖文件的测试包 |
| 标准 CurseForge 只有宣称支持 | 读取标准 manifest 和 overrides，按 projectID/fileID 从官方 API 精确解析必需 jar 模组，使用官方 URL、大小和哈希下载；先验证全部元数据再写入内容 | 有效标准包；受限下载 URL、缺 API Key、错误 ID、缺 hash/size；失败不得显示成功 |
| CurseForge 预览显示 0 文件却安装大量内容 | 预览计入真实 overrides 内容；需联网解析的文件单独计数，说明名称/体积/冲突暂无法确定 | 比较预览计数与包内文件及清单必需项 |
| 服务器整合包直接覆盖运行中的实例 | 拒绝运行中的服务器；核对已声明的 MC 版本/核心，确认覆盖后加入统一任务队列；缺信息或失败明确提示 | 运行中导入、排队后服务器启动、版本/核心不匹配、失败或取消 |

CurseForge 当前支持清单中明确的必需 `.jar` 模组和 overrides；可选项不会自动下载。缺少授权 URL、完整校验资料或无法确定目标分类的文件会明确拒绝。CurseForge 清单没有每个模组的端侧标记，服务器导入前会要求确认包适用于服务端；不会自动替换服务器核心，也不能保证任意客户端包适用于服务端。

批量内容导入不是整实例事务：取消或下载中断时，已经完成的内容可能保留；界面明确提示未完整导入，快速向导不继续启动部分失败的整合包。每个 ZIP 内容文件先写临时文件再提交，避免中断时截断同名旧文件。并发外部进程在检查与提交之间改动目录仍属于需要 Windows 压力验证的范围。

## 回归项目与当前验证限制

`Tests/ModpackImportRegression` 链接实际生产服务及安装编排，仅网络/Java/加载器/插件宿主用测试夹具替代；覆盖旧包保留、失败暂存清理、路径/链接拒绝、完整安装编排、端侧过滤和覆盖优先级、CurseForge 精确 ID 解析与未授权拒绝。

当前环境没有 .NET SDK，**尚未编译或执行这些 C# 回归**，也没有进行 Windows/WPF 界面、真实网络 API、真实 Minecraft/加载器启动、Windows 文件占用和目录联接实测。源码静态检查通过不代表以上运行验收已完成。
