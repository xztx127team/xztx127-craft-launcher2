# 设置搜索与修改管理

本轮设置相关改动对应 30 项体验改进中的第 1、2、11 项，以及新增功能的设置入口。

- 设置搜索现在遍历真实逻辑控件，折叠分区里的条目也能找到。跳转到结果时展开所在分区，保留既有隐藏设置的规则。使用清晰边框标记结果，不给文字添加模糊阴影，也不改变原控件的 Effect。
- 设置页内 `Ctrl+F` 定位搜索框，`Enter` / `Shift+Enter` 在结果间切换，搜索框内 `Esc` 清空搜索。不接管 F3 调试键。
- 135 个显式绑定的普通偏好控件，加上 Java 默认选择、窗口动作、下载源、搜索框布局、缩放绑定和各类动画控件，支持右键恢复单项默认值。组标题或控件右键菜单可恢复本组，执行前列出受影响项目并确认。重置遵循原有手动保存 / 自动保存流程。
- 重置不会删除已安装 Java、账号、实例、背景文件或其他游戏数据。访客会话、注册表权限、即时简洁模式、运行中的目标实例选择和取色器草稿不加入普通重置；这些仍使用原有专用入口。
- 底部只在确实有设置值变化后显示“查看本次修改”，保存后可查看最近一次保存的修改。文本输入只显示“文本已修改”，不把路径、地址等内容暴露在摘要中。搜索、滚动、展开分区、拖动滚动条、RGB 取色器未应用值不计为修改。普通模式下不保存的 Java 高级项不计入摘要。
- 右键性能悬浮窗对已保存字段的修改，会单独更新设置页相应基线，保留其它手动草稿。恢复界面布局也只同步受影响的几何布局字段，保留单独修改的搜索框透明度。下载面板限速、任务结果弹窗和最近使用菜单在其他位置保存的同一设置会按字段同步，不覆盖本页其它草稿。

## 低频设置入口与默认值

新增选项集中在默认折叠的“使用习惯、隐私与显示”分区，采用纵向排列和按内容自然定宽的按钮：

| 选项 | 默认 |
|---|---|
| 最近启动实例记录 | 关闭 |
| 最近使用工具记录 | 关闭 |
| 返回实例列表恢复筛选与位置 | 开启，仅本次会话 |
| 任务结果记录 | 开启，最多 100 条，仅本次会话 |
| 隐藏服务器地址 | 关闭 |
| 记住主窗口位置 | 开启 |
| 跟随系统减少动画偏好 | 开启 |
| 时间显示 | 跟随系统 |
| 容量显示 | 自动单位 |
| 显示精确字节数 | 关闭 |

清空最近使用记录同时清理实例和工具记录，并更新自动保存撤销快照，防止撤销其它设置后把记录恢复。关闭浏览位置记忆会清理旧会话状态；关闭任务结果记录会清理现有会话结果。

## 验证范围

已执行 `python Tests/SettingsUxSourceValidation/validate_settings_ux.py`，检查 XAML、135 个默认绑定的属性及控件存在性、重置确认、非破坏性排除、搜索边框、摘要隐私与草稿基线，以及新入口默认折叠和按钮布局约束。该脚本是源码契约检查，不是 WPF 运行测试。

仍须在 Windows 上编译并验收：

1. 在浅色 / 深色主题、854×480 及更大窗口、125% / 150% / 200% 系统缩放下打开设置，检查新分区布局与文本。
2. 搜索折叠分区的选项，验证结果跳转、高亮清除、隐藏选项和 F10 临时显示，以及搜索操作不触发保存提示。
3. 分别在手动保存和自动保存下，对单项及整组重置，验证撤销、保存和已有设置预览。
4. 修改多个设置，滚动、浏览下拉项、展开分区，确认摘要只记录实际可保存值；还原原值后该项从摘要中消失。
5. 保留设置草稿时右键修改性能悬浮窗，或恢复布局，确认无关草稿仍保留且已保存字段不被误判为待保存。
6. 开关最近实例 / 工具、任务结果和显示偏好；清空记录后执行设置自动保存撤销，确认不会恢复已清空记录。
