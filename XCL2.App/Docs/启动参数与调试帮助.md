# 启动参数与调试帮助

可运行 `XCL2.exe --help` 查看普通帮助，或 `XCL2.exe --debug --help` 查看实际调试快捷键表。调试、内存与减弱动效为本次会话覆盖，不保存到长期设置；直接启动游戏沿用原有账户与实例选择流程。

| 参数 | 效果 |
| --- | --- |
| `--debug` | 启用当前启动器会话的调试功能；F3 显示/隐藏实时信息；不隐式创建控制台 |
| `--debug-panel` / `--调试面板` | 开启调试并在首帧后显示面板 |
| `--home` / `--首页` | 打开首页 |
| `--instances` / `--实例` | 打开版本管理 |
| `--performance` / `--性能设置` | 打开性能悬浮窗详细设置，不自动开启监控 |
| `--play <实例名>` | 启动指定实例，省略账户时使用当前选中账户 |
| `--account <账户名>` | 为 `--play` 或旧 `-r` 明确选择账户 |
| `--open <页面名>` | 跳转页面；旧 `-gui` 保留 |
| `--settings`、`--downloads`、`--logs` | 分别打开设置、下载中心、日志 |
| `--window-size 1280x800` | 指定启动器窗口宽高；也可分别用 `--width` / `--height` |
| `--memory 2G` | 仅覆盖本次游戏最大堆，已有有效最小堆限制为不高于该值 |
| `--memory 500M:8G` | 明确指定最小堆和最大堆；旧 `--min-memory` / `--max-memory` 仍以 MB 为单位 |
| `--reduced-motion` | 本次关闭动效；`--no-animation`、`--no-animations` 为别名 |

示例：

```text
XCL2.exe --play "1.21.1-Fabric" --account Steve --memory 500M:4G
XCL2.exe --settings --window-size 1280x800 --reduced-motion
XCL2.exe --debug --logs
XCL2.exe --调试面板 --首页
XCL2.exe --启动 "我的 Fabric" --内存 500M:4G --减少动画
XCL2.exe --性能设置
```

参数名不区分大小写，值保留原大小写。带空格的值应由终端或调用程序正确加引号。既支持 `--参数 值`，也支持 `--参数=值`；值本身以 `-` 开头时使用等号，如 `--jvm-args=-Dexample=true`。显式值中的 `--debug`、`--help` 不会被再次识别成启动器选项。遇到未知参数、缺少值或无效数值时给出诊断并停止启动动作；帮助请求由入口优先显示。

窗口输入宽为 320–16384、高为 240–16384 像素；实际会按启动器界面最小尺寸与可用桌面范围调整。内存为正整数，可省略单位表示 MB，或使用 `M` / `MB` / `G` / `GB`；`1G=1024M`，最多 1048576 MB。范围必须最小值不大于最大值，不接受 NaN、Infinity、科学计数法或小数。多个覆盖按命令行出现顺序处理，最终显式最小堆不能大于最大堆。

旧 `-r --账户名 ... --实例名称 ...` 仍要求明确指定账户和实例；`--d` 的版本与加载器过滤、账户/实例列表、结果文件、一次性访客模式及内部重启接力参数继续支持。内部接力参数不出现在公开帮助中。`--debug -yrj` 的旧彩蛋组合继续保留，单独 `-yrj` 不启用彩蛋。

中文别名还包括 `--帮助`、`--调试`、`--设置`、`--下载`、`--日志`、`--打开 <页面名>`、`--启动 <实例名>`、`--内存 <值>` 和 `--减少动画`，与相应英文参数完全等效。

帮助正文只展示实际支持的参数。旧的未实现项（如 `--safe-mode`、`--debug-console`、`--theme`）仍明确报错并停止启动。`--java`、`--jvm-args`、`--game-args`、`--server`、`--fullscreen` 等已有高级启动选项继续支持；它们的值和版本兼容性仍由实际启动流程检查。

`Tests/CommandLineRegression` 使用真实解析器验证值消费、错误诊断、别名、有限数值、隐藏接力与帮助内容。当前环境没有 .NET SDK，尚未执行 C# 回归；Windows 实测还应检查实际实例启动、会话内存覆盖、窗口尺寸、动画覆盖与 F3 组合键。
