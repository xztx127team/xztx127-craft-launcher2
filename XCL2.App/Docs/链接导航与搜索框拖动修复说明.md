# 链接按钮、两级导航与搜索框拖动

## 链接按钮

服务器网络教程保留可直接打开网页的原链接，移除后面重复的四个「一键打开链接」。设置页的 Minecraft 日志入口已有网页打开能力，移除重复的浏览器按钮；XCL 日志和 DirectX 的浏览器选项使用说明目标的名称。更新日志和 Web2 操作按钮组采用可换行布局，统一间距。

Web2 的浏览器补充入口默认隐藏。只有主动打开的当前网址无法在内嵌页面加载，或 WebView2 组件/运行时不可用时，才显示外部浏览器入口。重试、成功加载、编辑网址和离开页面均清除旧状态。导航使用 WebView2 NavigationId 关联，旧请求的失败不能覆盖新请求；同网址重试及重定向也适用。外部链接仅接受 HTTP/HTTPS。

## 新界面预览

实际入口为现有 WPF 主窗口的预览模式。本次调整该入口：上方选择「启动、下载、联机、工具、设置」大类，左侧显示当前大类的小项目。

原来的页面实例、点击处理器、隐藏功能设置、账户/协议门控及插件权限检查继续使用。切换大类可返回该类上次实际打开的页面；若离开设置页被取消，选中状态跟随仍然显示的页面。插件按钮使用独立分类容器，分类筛选不覆盖按钮自身的显隐和禁用状态；加载后及刷新后同步选中状态。

顶部按钮在窄宽度下换行；左栏保留展开/收起，展开宽度同时考虑语言。弹窗、通知和遮罩覆盖导航与内容两行。关闭预览模式后恢复原有导航布局。独立的旧 WinUI 预览客户端没有改动。

## 搜索框长按拖动

原实现只依靠低优先级计时器进入拖动状态，移动事件可能在计时器获调度前永久取消长按。现在使用单调时钟判定按住 500ms，计时器和输入事件均能激活拖动。等待期间的手抖只更新锚点，不会永久取消或突然补跳。

保留边缘即时缩放、鼠标捕获、Esc 回滚、窗口失焦/调整大小时取消。编辑期间禁用触笔长按右键和轻拂，退出时恢复。短按、没有位移和取消回滚不会产生虚假的设置修改。搜索按钮内容垂直居中。
